# React Tic Tac Toe

This is a beginner React tic-tac-toe project built while learning components, props, click events, and the `useState` hook.

The board remembers nine square values, alternates between X and O, checks for a winner or draw, and can reset without reloading the page.

## Run the project

```bash
npm install
npm run dev
```

## Check the project

```bash
npm run lint
npm run build
```
