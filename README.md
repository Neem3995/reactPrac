# reactPrac

This repository holds my React classroom practice projects and lecture notes.

## Projects

- `react_tac_toe` - beginner tic-tac-toe project using components, props, and `useState`
- `ALAB-320H-1-1-React-Page-Layout` - employee directory layout lab
- `GLAB_320H_2_1` - simple React application guided lab
- `reactLectureNotes` - source files and notes from React lessons

Each runnable project keeps its own `package.json`, source files, and build setup inside its folder.

## Running a project

Open the project folder in the terminal, install its dependencies, and start Vite.

```bash
npm install
npm run dev
```
